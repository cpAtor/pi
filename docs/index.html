How to review before merge

Open docs/index.html from the PR artifact for quick review, or use the Pages-compatible workflow after merge or manual dispatch if Pages is enabled for GitHub Actions.
  • Local: serve the docs/ directory with any static file server and open this index page.
  • PR preview: the docs-preview workflow uploads the entire docs/ folder as an artifact.
  • Pages deploy: the optional pages-docs workflow can publish the same folder as a GitHub Pages site.
